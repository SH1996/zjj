# 竹间记 · 慢慢来

> 不急 · 想起什么就写一句

一个纯前端、零依赖的单页笔记应用：随手记录、待办与提醒、店铺送货清单（含拍照识别）、AI 语音整理、数彩实验室、手机推送、GitHub 私有仓库同步、时光机与周回顾。以 PWA 方式添加到主屏幕后可离线打开。

线上地址：https://sh1996.github.io/zjj/

## 数据存在哪里

- **默认全部在本机**：笔记保存在浏览器 `localStorage`（键 `bamboo.v11.*`），不上传任何服务器。
- **可选云端同步**：在「设置 → GitHub 同步配置」填入私有仓库与访问令牌后，笔记会同步到该仓库的 `notes.json`。同步目标必须是**私有仓库**；程序在写入前会校验 `private` 字段，公开仓库会被阻止写入。
- 云端同步使用墓碑并集 + `updatedAt` 新者胜做冲突合并，时光机可查看并恢复任意历史版本。
- 「导出本地备份」会下载包含笔记、墓碑与操作日志的完整快照（schema 2）；导入会覆盖当前数据，覆盖前会自动再下载一份当前快照。

## 配置说明

| 配置 | 用途 |
|---|---|
| AI 接口地址 / 密钥 / 模型 | 兼容 OpenAI 格式（如 DeepSeek），用于 AI 提炼、竹语、问一问、本周回顾、数彩实验室交叉解读 |
| 视觉模型 (Vision Model) | 拍照识别送货单用的多模态模型，默认 `deepseek-flash`；与文本模型分开配置 |
| 手机推送 Webhook URL | Bark 推送地址，页面关闭后仍可收到提醒 |
| 仓库所有者 / 名称 / 路径 / 分支 / 令牌 | GitHub 同步，仅用于你自己的私有仓库 |

### 安全须知（重要）

1. **只使用最小权限的细粒度令牌**：同步只需要目标私有仓库的 Contents 读写权限。切勿填入账户级经典 PAT（含 `delete_repo`、`admin:org` 等权限的令牌）。
2. **API 密钥与访问令牌以明文保存在本机浏览器的 `localStorage`**。设置面板不会回显已保存的凭据（留空表示不修改）；请勿在公用设备上保存高权限凭据，离开时可用「断开配置」清除。
3. 启用 AI 后，相关笔记内容会发送到你填写的模型服务；**已删除的笔记不会外发**。「拍照识别」会把送货单照片发往视觉模型，照片只在内存中压缩处理，不写入 `localStorage`、不进入备份与云端同步。「数彩实验室」仅在你点击 AI 解读后发送统计摘要与候选，不发送笔记、凭据或完整历史数据。Bark 推送的正文会按 URL 编码后的长度截断，避免中文长笔记把推送 URL 撑得过长。
4. `.gitignore` 已排除 `notes.json`、`*.txt` 等，避免把真实笔记提交进公开仓库。

### 提醒的局限

提醒依赖页面在前台运行（15 秒轮询 + 浏览器通知）。页面被关闭或系统冻结后台时不会触发；需要离线提醒请配置 Bark。浏览器通知权限需由用户点击后授予。

## 项目结构

```
index.html      笔记主应用与全部界面样式（原生 JS，无构建步骤）
lottery-data.js 发布时从官网读取并校验的双色球 120 期 / 大乐透 100 期真实历史数据
lottery.js      数彩实验室：数据校验、统计算法、候选生成、回测与独立全屏界面
manifest.json   PWA 清单
sw.js           Service Worker：页面网络优先、静态资源缓存优先，API 请求直连不缓存
icons/          应用图标（含 maskable）
```

改 `index.html` 后直接推送到 `main`，GitHub Pages 会自动部署。**发布新版本时请同步更新 `sw.js` 里的 `CACHE` 名称**，否则旧缓存不会失效。页面版本由 `index.html` 顶部的 `APP_VERSION` 常量维护；`localStorage` 键名沿用 `v11` 不变，不要改名，否则用户数据会丢失。

### 拍照识别使用说明

1. 在「设置」里填好 AI 接口地址与密钥，并确认「视觉模型」为 `deepseek-flash`（或你的中转服务提供的视觉模型名）。
2. 打开「送货单」→ 点「选择 / 拍照图片」，可一次选多张送货单照片 → 点「✨ AI 识别并填入表格」。
3. **核对**表格中的日期、送货商、送货商的联系方式与每行货品（AI 识别可能有误），确认无误后点「保存清单」，即按固定格式存档到「店铺」分类。
4. 同一天、同一送货商、同一联系方式的清单会自动归集合并，不会生成重复存档。
